Na primeira etapa escolhi como site para replicar a tela de login da netflix. Para começar criei o esqueleto da página, com todas as frases e botões. 

Foi adicionado o rodapé da pagina, fiquei na dúvida sobre os links, mas como a atividade pedia apenas uma página apenas os adicionei. Em seguida foi começado o style.css onde defini o fundo preto e a fonte branca, utilizando o método mobile first.

Foi estilizado o formulário e o botão de continuar, além de algumas alteração no index, como optar por utilizar placeholder para deixar o texto mais organizado dentro do formulário.
